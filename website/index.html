01

Features

Everything a Soroban dev needs, in one CLI

sdkt consolidates the full developer lifecycle — contract inspection, invocation, XDR decoding, storage TTL management, security auditing, WASM diffing, and deployment — into a single CLI.

Contract Invocation

State-changing execution in one command (sequence → simulate → sign → submit → poll) with sdkt invoke, or instant read-only simulation with sdkt call.

Contract Inspection

Read a contract's ABI, functions, events, and metadata from compiled WASM or live on-chain contracts. sdkt wasm inspect · sdkt inspect

Storage & TTL Management

Analyze storage rent and categorize entries (sdkt storage analyze), read typed entries (sdkt storage read), and extend footprint TTL (sdkt storage extend).

Event Explorer

Query, filter, and inspect contract events across ledger windows with on-chain or local ABI decoding. sdkt events

Static Security Audit

Static analysis of contract source against AUTH-001/002/003/004 and MOVE-001 rules — no network, no secrets. sdkt audit

AUTH-001
Privileged/admin function missing require_auth()
AUTH-002
Cross-contract invoke_contract() without require_auth()
AUTH-003
Unguarded initialize() entrypoint
AUTH-004
Token transfer without require_auth() on source or destination
MOVE-001
Suspicious move-after-use heuristic (Warning)

Upgrade Safety Diff

Diff two WASM files offline and get a breaking-change verdict before deploying. sdkt diff --upgrade-safety

Build & Deploy

Compile contracts into WASM and deploy with automated salt generation, constructor arguments, and a --deny-breaking upgrade guard. sdkt deploy

Identity & Keystore

Manage ED25519 local signing identities offline (sdkt identity) and fund testnet accounts with one click via Friendbot (sdkt identity fund).

Account & Fee Insights

Inspect account balances, sequence numbers, and signers with sdkt account, and query dynamic base fee estimates with sdkt fee estimate.

XDR Encoding & Decoding

Decode base64 XDR to JSON for ScVal, envelopes, and events (sdkt decode), or encode typed values into XDR (sdkt encode).

Transaction Pipeline

Granular manual control to build, validate, simulate, sign, and submit envelopes — with fully offline ED25519 signing. sdkt tx *

Plugin System

Extend sdkt audit with custom rules. Pack, verify, install, and execute plugins automatically via sdkt plugin. Supports native and WASM plugins.

04

Why Soroban DevKit

One CLI instead of a pile of scripts

Soroban developers work across multiple development workflows including contract inspection, invocation, XDR handling, storage and TTL management, static security review, transaction simulation and signing, and deployment.

In practice that means context-switching across several CLI tools and hand-written RPC scripts. Soroban DevKit brings the supported workflows into a unified CLI with consistent flags, consistent --format json output, and an offline-first default.

  • Offline-first. decode, diff, audit, wasm inspect, and tx sign need no RPC and no secrets leaving your machine.
  • Upgrade safety as a gate. Breaking-change verdicts you can run in CI before a contract upgrade ships.
  • Scriptable. JSON output on most commands, plus shell completions for bash, zsh, fish, powershell, and elvish.
  • Extensible. The audit engine loads third-party rules as sandboxed WASM plugins or native shared libraries.
05

Stellar / Soroban

Built for the Soroban ecosystem

Soroban DevKit is built specifically for the Stellar Soroban developer ecosystem. It speaks Stellar XDR natively, reads contract state through the Soroban RPC interface, and enriches account data via Horizon.

Networks are addressed by named profile or explicit endpoint, with a built-in testnet default and an explicit guard when targeting mainnet.

  • Soroban RPC. Contract inspection, storage and TTL reads, events, contract invocation (invoke & call), transaction simulate/submit, fee statistics, and on-chain WASM metadata.
  • Stellar XDR. ScVal, TransactionEnvelope, and ContractEvent decoding, plus typed envelope construction and ED25519 signing.
  • Horizon. Account balances and signers via sdkt account.
  • Network profiles. Save an RPC URL, passphrase, and Friendbot faucet once, reuse it from any RPC command.

Installation

Running in under five minutes

Pick an install method, verify, then run your first command.

curl · install.sh 
# downloads the release binary for your OS/arch,
# verifies its SHA-256 checksum, installs to ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/SaboLabs/soroban-devkit/main/install.sh | bash
# verify
sdkt --version
crates.io · cargo install sdkt-cli 
# requires Rust 1.88.0+
cargo install sdkt-cli

# build from source
git clone https://github.com/SaboLabs/soroban-devkit
cd soroban-devkit
cargo install --path crates/sdkt-cli

Verify the install with sdkt --version, then explore the full command set with sdkt --help. Shell completions for bash, zsh, fish, powershell, and elvish are generated with sdkt completions. The crates.io package is named sdkt-cli; when its published version trails the GitHub release, use install.sh or build from source to get v2.5.0.
