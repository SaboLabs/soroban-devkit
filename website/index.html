Quickstart

First check in under five minutes.

All four steps run offline. No RPC, no account, no network.

install · inspect · audit · fuzzoffline
# 1. install (pick one)
curl -fsSL https://raw.githubusercontent.com/SaboLabs/soroban-devkit/main/install.sh | bash
# or: cargo install sdkt-cli

# 2. inspect a contract WASM
sdkt wasm inspect crates/sdkt-cli/tests/fixtures/us_old.wasm

# 3. audit contract source
sdkt audit examples/sample_token/src/lib.rs
# -> [critical] AUTH-001 [SampleToken::admin_action]

# 4. first fuzz campaign
sdkt fuzz campaign crates/sdkt-cli/tests/fixtures/us_new.wasm --seed 42 --cases 4
