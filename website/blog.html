What's new

Release 2026-10-05

v2.7.0 — Deployment verification, network diagnostics, audit ABI correlation

Major additions: sdkt deployment-verify for on-chain artifact verification, sdkt network diagnose for read-only network health checks, and sdkt audit --abi for spec-correlated static analysis. Also includes getNetwork robustness fix for SDF endpoints, opt-in WASM size policy, and contract metadata inspection.

View release → Changelog →
Release 2026-10-02

v2.6.0 — Release assurance, event filtering, envelope decode, storage diff plans

Introduces sdkt release-assurance for aggregated release verdicts, sdkt events --topic for server-side event filtering, sdkt tx decode for human-readable envelope inspection, and sdkt storage storage-diff --extend-plan for TTL extension planning. Also includes constructor argument support in deploy, configurable event ranges, network-aware fee estimation, and plugin scaffolding.

View release → Changelog →
Release 2026-08-08

v2.5.0 — Release polish, mainnet safety, shell completions

Adds containerized distribution, a safety guard for mutating mainnet commands, sdkt completions for five shells, and opt-in version provenance. Also includes supply-chain auditing and hermetic CLI integration coverage.

View release → Changelog →
Release 2026-08-07

v2.4.0 — Named network profiles for RPC commands

Adds sdkt network profiles to save RPC URLs and network passphrases, with profile selection and explicit endpoint overrides across RPC commands.

Release 2026-08-07

v2.2.0 — Offline transaction signing

Adds sdkt tx sign to sign transaction envelopes offline with a local ED25519 identity and completes the build, sign, and submit workflow.

v2.1.0 — RPC simulation metadata and connection pooling
