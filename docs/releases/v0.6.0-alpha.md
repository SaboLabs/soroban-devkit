# Release Notes: v0.6.0-alpha

**Release Date:** 2026-08-04

## Overview
Soroban DevKit (`sdkt`) v0.6.0-alpha marks the completion of Milestone 6, shifting focus entirely toward production readiness, resilience, and developer experience. No new user-facing CLI features were added in this release cycle. This is a stabilization, quality, and hardening release.

## Features
*(Consolidated from previous milestones, stabilized in v0.6.0-alpha)*
- XDR Decoding (`sdkt decode`)
- Contract Storage Inspection (`sdkt inspect`)
- Storage TTL Analysis (`sdkt storage check`)
- Transaction Inspection (`sdkt tx inspect`)
- Event Explorer (`sdkt events`)
- Account Inspection (`sdkt account`)

## Workspace Architecture
The project is cleanly separated into 5 core crates to ensure modularity:
- **`sdkt-cli`**: Output formatter and argument parsing.
- **`sdkt-core`**: Configuration and shared types.
- **`sdkt-rpc`**: Soroban RPC networking, timeout handling, and retry logic.
- **`sdkt-storage`**: Storage analysis.
- **`sdkt-xdr`**: XDR encoding/decoding via `stellar-xdr`.

## Examples

Check transaction and format output as pretty JSON:
```bash
sdkt tx inspect <HASH> --format json
```

Check a smart contract's storage limits:
```bash
sdkt inspect <CONTRACT_ID>
```

## Known Limitations
- **Account Inspection**: Currently returns placeholder boundaries for account graphql/horizon equivalents. Full horizon REST integration pending Milestone 7.
- **Event Parsing**: Events return base64 XDR; full ScVAL expansion into UI-friendly topics is still in progress on the `sdkt-xdr` boundaries.

## Production Readiness Improvements (v0.6.0-alpha)
- RPC resilience: `reqwest` now configured with explicit `timeout` (15s) and a bounded single-attempt retry mechanism for networking failures.
- Strict compiler guidelines: 100% `-D warnings` compliant workspace-wide.
- Open Source Hardening: Added `LICENSE` (MIT/Apache 2.0), `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `.gitignore`.
- CI/CD Setup: Enabled GitHub Actions pipeline covering `fmt`, `clippy`, and `test`.

## Next Roadmap
Milestone 7 will target deeper Stellar Horizon REST parsing (Accounts) and comprehensive UI layout mapping for ScVALs in CLI Pretty outputs.
