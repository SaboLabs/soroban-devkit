# Sabo Labs

Sabo Labs builds open-source developer tooling focused on the Stellar
ecosystem, including the Stellar/Soroban smart-contract platform.

## Projects

### Soroban DevKit (`sdkt`)

Offline-first CLI and Rust toolkit for Soroban contract development.

- Inspect, decode, and analyze compiled contract WASM offline
- Static security analysis (`sdkt audit` with built-in and plugin rules)
- Offline WASM diffing with upgrade-safety verdicts (`sdkt diff --upgrade-safety`)
- Typed transaction envelope builder, signing, simulation, and submission
- Multi-contract workspace orchestration with topological dependency sorting
- Named network profiles and ED25519 identity keystore

- Repository: https://github.com/SaboLabs/soroban-devkit
- Docs: https://sabolabs.github.io/soroban-devkit/
